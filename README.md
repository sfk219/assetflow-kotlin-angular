# AssetFlow — Kotlin · Spring Boot · Angular · MongoDB

A portfolio full-stack asset lifecycle management demo combining **Kotlin 2.x, Spring Boot, Spring Data MongoDB, Angular, TypeScript, REST APIs, and Docker Compose**.

Features: asset records with unique serial numbers, REST endpoints, validation, search and pagination, dashboard forms, filtering and summary statistics.

**Architecture:** Angular web client → Spring Boot API → MongoDB.

Run locally after source files are added with `docker compose up --build`. This is independent demo code based on fictional data, not employer/client source. Authentication and public deployment security are outside demo scope.
